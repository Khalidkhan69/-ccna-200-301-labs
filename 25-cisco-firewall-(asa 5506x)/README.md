# Lab 25 — Cisco Firewall (ASA 5506-X)

## Overview
This lab explores the Cisco ASA 5506-X firewall and its role in protecting a network by controlling traffic between network security zones.

## Objectives
- Understand the purpose of a Cisco ASA firewall.
- Explore firewall interfaces and security levels.
- Configure IP addressing where supported.
- Apply traffic filtering rules and Access Control Lists (ACLs).
- Test connectivity and troubleshoot firewall access.

## Lab File
- Cisco ASA 5506-X Packet Tracer lab file

## Key Concepts
- Firewall fundamentals
- Interface security levels
- Access Control Lists (ACLs)
- Traffic filtering
- Network security and troubleshooting

## Verification Commands
Use commands supported by the device or simulator:
- `show interface ip brief`
- `show running-config`
- `show access-list`
- `show route`

## Expected Results
- Firewall interfaces are configured according to the topology.
- Traffic filtering rules behave as intended.
- Connectivity tests verify permitted and denied traffic.

## Technologies Used
- Cisco Packet Tracer or the simulator used
- Cisco ASA firewall
- IPv4 networking and ACLs

## Learning Outcome
Practiced firewall concepts, traffic filtering, and network security verification.
