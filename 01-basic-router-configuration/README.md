# Lab 01: Basic Router Configuration

## Objective

Configure the basic settings of a Cisco router using the Cisco IOS command-line interface.

## Skills Practiced

- Navigating Cisco IOS modes
- Configuring the router hostname
- Configuring interface IP addresses
- Enabling interfaces with `no shutdown`
- Viewing the running configuration
- Saving the configuration

## Verification Commands

```cisco
show running-config
show ip interface brief
```
